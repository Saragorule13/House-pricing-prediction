# Housing Price Prediction using Linear Regression 

This project builds a **Housing Price Prediction** model using **Linear Regression** with **scikit-learn**.  
Given features like house size and house price the model predicts the **price of a house**.

---

## 📌 Project Overview

- Problem Type: **Supervised Regression**
- Algorithm: **Linear Regression** (from `scikit-learn`)
- Goal: Predict **house prices** based on given features.
- Tech Stack:
  - Python
  - scikit-learn
  - pandas
  - NumPy
  - matplotlib 

---
